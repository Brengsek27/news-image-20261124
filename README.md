A program that writes one image summing up Tuesday 24 November 2026 world news, featuring 70 verified stories: 20 illustrated cards and 50 numbered briefs spanning seven global regions. The design presents a charcoal and gold broadsheet layout at 1024x1024 pixels.

## How to Run

- `python3 render.py` - Generate the news image
- `node main.ts` - Validate and copy the entry image
- `python3 verify.py` - Run all verification checks
